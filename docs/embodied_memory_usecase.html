Benchmark Tasks — 评估任务

  • Swap 3 Mugs — 需记住哪些杯子已交换，避免重复操作
  • Find Object — 记忆已搜索区域，系统性探索未知区域
  • Unpack Groceries — 追踪已归位物品，管理多阶段解包流程
  • Scoop Coffee — 计数已舀次数，精确控制份量
  • Grilled Cheese — 时间推理 (计时翻面)，15 分钟长时域任务
  • Window Cleaning — 空间记忆，追踪已清洁/未清洁区域

Core Insight — 核心洞察

  • 双通道互补 — 短期视觉记忆捕捉运动细节，长期语言记忆维护抽象进度
  • 主动遗忘 — 不是记住一切，而是选择性记忆 + token 压缩，保持实时性
  • 同源生成 — 记忆写入与动作生成在同一次 VLM 推理中完成 (CoT)
  • 100x 时域扩展 — 从典型 ~10 秒 demo 扩展到 15 分钟连续任务
  • 涌现能力 — In-context adaptation, 时间推理, 因果去混淆均为记忆机制的涌现行为
  • 类比人类 — 短期 ≈ 工作记忆 (视觉缓冲), 长期 ≈ 情景记忆 (语言叙事)
